About Gallery

Welcome to my Photo Gallery project! This website is created using HTML, CSS, and JavaScript to showcase beautiful images in a modern and interactive way.

The gallery includes different categories like Nature, Animals. Users can easily filter images using buttons and view them in a fullscreen lightbox.

This project demonstrates important front-end concepts such as grid layout, responsive design, hover effects, and JavaScript functionality like image filtering and navigation (next/previous images).

The main goal of this project is to create a clean, user-friendly and visually attractive image browsing experience.
